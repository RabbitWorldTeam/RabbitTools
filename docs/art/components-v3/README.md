# Simple component artwork v3

Current designs for building_component, precision_building_component and blank_core. Created with built-in imagegen on 2026-11-08, using the original angel-core sprite as a simplicity/style reference. This revision replaces the dense mechanical-assembly artwork, preserving the other five wand-head textures.

## Native texture design

All three final textures are 16x16 RGBA with a centered 10x10 footprint. The building-component silhouette is shared across all three. They use large solid face colors, a chunky material rim, a short upper-left highlight and one contrasting center contact/socket. No gears, rivets, wires or fine surface detail remain.

Generated sources are saved as <item-id>-source.png. For export, the opaque sprite bounding box is sampled by nearest neighbor into a 10x10 region with 3 pixels of transparent padding. Each sample is mapped to its nearest declared palette color from export-palette.json; alpha is binary. The first component's silhouette is reused for the other two; nearest opaque source colors fill any edge difference. This limits each image to at most 8 opaque flat colors and avoids high-resolution shading turning into noise at native size.

components-native.png contains the three 16x16 textures in order at actual size; components-preview.png is an exact 8x nearest-neighbor enlargement. previous-textures/ retains the replaced artwork. Item IDs, recipes, functionality and wand-head textures are unchanged.

Design a new crafting component using that same simple core design vocabulary. A single chunky clipped-corner SQUARE TOKEN, front-facing, with one solid inset square plate and ONE central 2x2 logical pixel square contact/socket. No gemstones with faceting, no gears, no cogs, no screws, no rivets, no cables, no small parts, no holes except the depicted center square, no concentric rings. Treat the entire canvas as EXACTLY 16x16 logical pixels: the complete item occupies only a 10x10 logical pixel footprint centered with THREE transparent logical pixels padding on each side. Outer rim is ONE logical pixel thick, interior is a few big solid flat color regions. Materials/colors: copper-brown outer rim, silver-gray inset plate, ONE small dark-red 2x2 pixel square contact in the center; pale silver top-left highlight; 7 colors maximum. One small upper-left highlight strip and one darker lower-right shade, like the original core, nothing else. Strict uniform square pixels, no extra detail below one logical pixel, no fine border outlines, no textures, no gradients, no antialiasing, no glow, no drop shadow. Truly transparent background. No text or labels. This image will be reduced to exactly 16x16 and MUST be immediately recognizable at native size. Prioritize a strong simple silhouette and just 1 center marker over all decorative detail.
