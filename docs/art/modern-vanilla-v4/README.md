# Modern vanilla material treatment v4

Current artwork for the three components and five wand heads. Created with the built-in imagegen tool on 2026-11-08, following the user's requested modern 1.14+ vanilla/Jappa visual direction. The original user constraints are recorded as the project art guide in docs/ART_STYLE.md.

## Production method

1. Keep exact existing 16x16 alpha masks, silhouettes, padding and principal material/marker identities.
2. Use local Minecraft 1.21.1 iron, copper, gold, diamond, netherite, amethyst and redstone icons as material/shading references. Those reference PNGs stay in ignored build/reference/modern-vanilla and are not packaged.
3. Generate recolor/shading edits with reduced extremes, coherent pixel clusters, cool or reddish-purple shadow shifts, warm localized highlights and selective colored outlines.
4. Sample the generated visible bounding box into the existing native sprite footprint. Use the original per-pixel alpha mask. Normalize RGB to the deliberate material ramps in source-manifest.json, avoiding pure black, pure white and neon ramps. The export script is scripts/Export-ModernVanillaTextures.ps1.
5. Inspect the actual final 16x16 pixels using exact nearest-neighbor previews; the generated large source image is not the delivered texture.

Original generation PNGs are retained as <item-id>-source.png, and the previous native textures are in previous-textures/. textures-native.png is an actual-size 80x32 sheet. textures-preview.png and textures-before.png are exact 8x enlargements. Top row: building component, precision component, blank core. Bottom row: iron, gold, diamond, netherite, infinity heads.

The material choices are deliberate art direction, not a claim of official artist approval or pixel-perfect identity with vanilla assets. No item IDs, recipes, mechanics or source code behavior change in this revision.
