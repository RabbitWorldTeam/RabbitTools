# Wand head artwork

Generated with the built-in imagegen tool on 2026-11-08. Original angel, destruction and exchange core textures provided the silhouette/style references. Each new material head uses the same compact diagonal beveled gemstone family. The iron generation served as a shared silhouette reference for the other four variants.

Source PNGs are retained here as <material>-source.png. Inventory textures are 16x16 RGBA with a centered 10x10 sprite footprint. The preview sheet is an exact nearest-neighbor enlargement of the final item textures, ordered iron, gold, diamond, netherite, infinity.
